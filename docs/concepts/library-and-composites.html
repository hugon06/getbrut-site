Library & composites

Reuse is first-class in Brut. A pipeline you've perfected shouldn't be rebuilt by hand on the next job — collapse it, save it, drop it in anywhere.

#Groups

Select two or more nodes and press Ctrl+G (or Group in the floating selection bar, or the rail's Organize section) to wrap them in a labeled frame. A group is purely visual — it moves as a unit and keeps things tidy. ✕ on the frame ungroups.

Select a group to style its identity: six frame colors (dashed line + background wash) and a label size up to genuinely gigantic — big enough to read the group's name zoomed all the way out.

Groups also adopt: drop a node inside a group's area (or add one there from the Tab menu) and it joins the group automatically — drag it out and it leaves. No re-grouping ceremony.

#Composites

A composite is a subgraph collapsed into a single node (select nodes → 📦 Collapse to composite). Cut wires become labeled ports; the inner nodes are still real (just hidden), so caching, pins and ledger history keep working inside the composite exactly as outside.

  • Open / Close — ⤢ opens a composite into a live frame you can edit inside, then ⇱ packs it back up, exactly where it was, with the same ports (new outside wires you made while it was open become new ports). Only nodes that are members of the frame close into it — a node you add or drag inside joins automatically; a node that merely overlaps the frame's area stays out.
  • Run — ▶ on a composite runs its whole inside plus everything upstream.
  • Preview — a closed composite shows the images its output ports currently carry, one thumbnail per result captioned with the port name, read live from the nodes inside: it is there before any run, survives Open / Close, and updates as inner nodes finish. 🔍 pages through them like any node result; right-click reveals the file.
  • Explode — 💥 permanently dissolves it back into loose nodes.
  • Knobs — a closed card can show a few of its inner fields on its own face: a prompt variant as a select, a brief as a text box, a shot count, or the model of a generation stage (a route-aware menu, like the stage's own picker). ⚙ Add knob on the card exposes one field (node.field, a label, the control, the select's options one per line as label | value); × on a knob removes it. A knob writes straight into the node inside, so it costs exactly what typing on that node would: an edit is one undo step, a changed prompt or model re-renders that stage only, everything else stays cached. A select whose inner text was edited by hand shows (custom) rather than pretending. Knobs survive Open / Close and travel with the composite into the library; Marcel sets them by name.

Composites are how any tuned chain — say, your Director with its house style plus its Storyboard — becomes one droppable node.

#The global library

Templates are also laid out on the home screen's Start from row (drawn as the glyphs of the nodes they contain, filtered by type); composites and presets stay here in the Library, since they belong to a graph rather than start one.

Composites, whole-graph templates and presets can be saved to a global library — deliberately cross-project, so the same shelf appears on every project.

  • Save a composite — 💾 Save to library on the composite node. Same name = a new version (everything is versioned; any past version is retrievable).
  • Save a graph as a template — File ▾ → Save graph as template….
  • Save a preset — 💾 on the node that owns the settings: the Prompt node and Multi-Shot notes save prompt presets (reusable brief texts), the Upscale Image node saves upscaling presets (model + dials).
  • Browse — File ▾ → Browse library…, or find saved composites right in the Tab add-node menu under Library. Dropping one in gives it fresh ids (separate caches, no collisions). The Library panel also lists every preset, grouped by what it belongs to — presets are applied from their node, and deleted here.

Library items carry an optional category (a shelf label you pick on save) and hold sanitized recipes only — prompts, models and wiring. No images, no caches, no keys are ever written into a library item, so they're safe to share.

Some items ship with Brut — like the Cinema Director template (the whole cinema pipeline, pre-wired) and the Character Lab composite: drop it into any graph, wire a full-body character image in, and it produces an expression grid, a clean head-to-toe studio portrait (clothes kept — describe an outfit in the stage prompt to re-dress instead), and a clean 4-view turnaround sheet — open (⤢) it to edit the three stage prompts. The three stages come preset to GPT Image 2 (auto aspect, 1K, high quality) — the safe pick for people, since Gemini can silently refuse images resembling real persons — and you can swap models on any stage. Built-ins can't be deleted; saving your own item under the same name shadows the shipped one.

#Templates vs composites

  • A composite is a node — a reusable building block you drop into an existing graph.
  • A template is a whole graph — a starting point for a new job, opened fresh from the library.
