Anthropic

Anthropic's Claude joins Brut as a planning model — text only. It generates no images or video; it's there to be your director: writing the concept, look and shot plan on the Director node, and powering the Refine node.

#Claude Sonnet 5.5

New on 28 September 2026, in Brut the day Anthropic released it. Sonnet 5.5 is Anthropic's newest Sonnet: faster and sharper than Sonnet 5, at the same price.

  • Marcel's default brain. With an Anthropic key, Marcel's Auto brain is now Sonnet 5.5 (it was Sonnet 5). A brain you picked yourself in ⚙ Settings → Marcel stays picked.
  • In every model picker: the Director, the crew agents, Text→Text, Refine and Marcel. It runs on your Anthropic key, or through OpenRouter at the same rates.
  • Price: $2 in / $10 out per million tokens, the same as Sonnet 5. Marcel's long system context is cached, so after the first message of a session each turn costs cents.
  • Reasoning goes from low to max (default high). Thinking off means no thinking before acting on this model, and works at low, medium or high effort only. Details under Reasoning dial & thinking switch.
  • Marcel keeps talking while he works. Sonnet 5.5 (and Opus 5.5) write their notes between actions in a new form that stays hidden unless the app asks for it. Brut asks for it on every acting turn, so the notes appear in the chat as before. It also hands each step's reasoning back to the model unchanged, as Anthropic requires. Without that, Marcel went quiet mid-action and later apologised for notes you never saw.

#Claude Haiku 5.5

New on 7 October 2026, in Brut the next morning. Haiku 5.5 is Anthropic's new small model: a tenth of Haiku 4.5's price, a 1M-token context, and the same two knobs as the big Claudes.

  • The narrator's new default. With an Anthropic key, Marcel's Auto narrator lane (failure diagnoses, run commentary, recaps, the quiet taste passes) now runs on Haiku 5.5. A narrator you picked yourself stays picked. It is also in every text picker: the Director, the crew agents, Text→Text, Refine and Marcel's brain.
  • Price: $0.10 in / $0.50 out per million tokens for prompts up to 100,000 tokens. Over 100,000 tokens a prompt pays five times that ($0.50 / $2.50): the one current Claude priced by prompt length. Brut's estimates and ledger rows apply the higher rate when a call's prompt passes the line, which a long chat on Marcel's full knowledge can do; the narrator's few hundred tokens never do.
  • Reasoning goes from low to max; thinking is adaptive by default and switches off cleanly (a plain off, unlike Sonnet 5.5's "no thinking before acting").
  • Runs on your Anthropic key, or through OpenRouter at the same base rates.

#Get a key

Create a key in the Anthropic Console and paste it into ⚙ Settings → Anthropic (Claude). Brut validates it by listing models.

#How it's used

Anywhere Brut asks "which LLM should plan this?" — the Director (and the legacy crew agents), Text→Text and the Refine presets — you can pick Claude, Gemini or GPT. Claude reads your stills (multimodal, downscaled to fit the request cap; generation always uses full-resolution images) and returns the strict JSON plan the chain expects.

#Reasoning dial & thinking switch

Claude Sonnet 5.5 (Anthropic's newest Sonnet, in Brut since its release day, 2026-09-28), Sonnet 5, Opus 4.8, Opus 5 (added 2026-08-23) and Opus 5.5 (launched 2026-09-22, in Brut since 2026-09-24) carry the knobs Brut exposes wherever these models run — the Text→Text node, the cinema agents, and Marcel's brain lane:

  • Reasoning effort (low → max): how deeply the model reasons before answering. Deeper = better on hard treatments, more output tokens billed. Claude's own default is high on every model but Opus 5.5, whose default is medium: on 5.5, set the dial when you want the deep end.
  • Thinking switch (Marcel's brain, ⚙ Settings): Claude Sonnet 5.5, Sonnet 5, Opus 4.8 and Opus 5 think adaptively by default, and those thinking tokens bill as output tokens — so if Marcel feels slow or a chat turn costs more than expected, switching thinking off is the lever: faster, cheaper, a little shallower. The switch needs your native Anthropic key (turns routed through an aggregator can't carry it — Brut refuses loudly rather than silently thinking anyway). Opus 5.5 has no switch: its thinking is always on (Anthropic rejects "off"), so the row reads not supported and the cost lever there is a low effort. On Sonnet 5.5, off means "no thinking before acting": Anthropic's lowest setting on that model still lets it write short progress notes between actions, and it works at low, medium or high effort only (with the dial at xhigh or max, Brut asks you to lower it or turn thinking back on).

Haiku 5.5 carries both knobs too (thinking adaptive by default, a plain off). Haiku 4.5 supports neither (it was the narrator lane until Haiku 5.5 took over).

#Which Claude for what

  • Sonnet 5.5 ($2 / $10 per million tokens in / out): Marcel's default brain since 2026-09-28 and the everyday planner, faster and sharper than Sonnet 5 at the same price.
  • Sonnet 5 ($2 / $10): the previous Sonnet, still listed for graphs and lanes that picked it.
  • Opus 5.5 ($4 / $20): the powerhouse brain, Opus-tier reasoning below Opus 5's price. Prompt-cache reads bill at 0.05× the input rate on this model, half the usual, so long Marcel sessions stay cheap.
  • Opus 5 and Opus 4.8 ($5 / $25): still listed for graphs and lanes that picked them.
  • Haiku 5.5 ($0.10 / $0.50 up to 100K tokens of prompt, $0.50 / $2.50 above): the narrator lane since 2026-10-08, and the cheapest Claude for Refine and Multi-Shot plans.
  • Haiku 4.5 ($1 / $5): the previous narrator, still listed for lanes that picked it.

List rates as pinned in Brut's catalog on 2026-10-08; every ledger row prices from the tokens the provider reports, never from a guess.

#Notes

  • Truncation is handled loudly: a stop_reason: max_tokens triggers one retry with more headroom, then a clear failure — never a silently cut-off plan.
  • Because Claude is text-only, it never enters the paid generation queue — it's a cheap planning brain, not a renderer.

For available model ids and pricing, see Anthropic's console; Brut's catalog lists the ones it exposes.
